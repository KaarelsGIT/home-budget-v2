# HomebudgetV2 Monorepo

This repository contains two applications:

- `backend/` - Spring Boot API
- `frontend/` - Angular web application

## Run Backend

```bash
cd backend
./gradlew bootRun
```

## Run Frontend

```bash
cd frontend
npm install
npm start
```

## Build

Backend:

```bash
cd backend
./gradlew clean build
```

Frontend:

```bash
cd frontend
npm install
npm run build
```
